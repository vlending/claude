# KBO Fan MVP Prototype

React + TypeScript + Tailwind 기반의 모바일 우선 단일 페이지 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 프로토타입 구성

- 홈: 오늘 경기 상태/스코어/투표 가능 여부
- 경기 상세 & 투표: 후보 카드, 투표권, 광고 시뮬레이션(+3)
- 결과: 득표율, 최종 Fan MVP, 적중 여부, 언더독 보너스
- 내 랭킹: 적중률, 참여/적중 경기수, 연속 적중, 포인트, 티어
- 전체 랭킹: Top 10 닉네임/포인트/티어/응원팀
- 제안 요약: KBO 공식 제안용 메시지

## 데모 플로우

1. 홈에서 경기 선택
2. MVP 후보 확인
3. 투표권 부족 시 `광고 보고 투표권 받기`
4. `투표하기`
5. `결과 공개`
6. 적중 여부와 포인트 반영 확인
7. 내 랭킹/전체 랭킹 확인
